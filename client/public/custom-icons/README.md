# Custom AI-Generated Whiteboard Icons

Drop your AI-generated SVG or PNG icons directly into this folder!
The whiteboard will automatically pick them up or you can register them in `CustomToolbarIcons.jsx`.

### Standard File Names:
- `select.svg` (or .png) - Selector / Cursor tool
- `pen.svg` (or .png) - Pen tool
- `highlighter.svg` (or .png) - Highlighter tool
- `eraser.svg` (or .png) - Eraser tool
- `line.svg` (or .png) - Line tool
- `shape.svg` (or .png) - Shapes tool
- `text.svg` (or .png) - Text tool
- `ruler.svg` (or .png) - Straight Ruler instrument
- `compass.svg` (or .png) - Pair of Compasses
- `protractor.svg` (or .png) - 180° / 360° Protractor
- `divider.svg` (or .png) - Measuring Divider
- `setsquare.svg` (or .png) - Set-Square / Triangle
- `math_tablet.svg` (or .png) - Math formula recognition tablet
- `graph_plotter.svg` (or .png) - 2D/3D Graphing panel
- `physics_space.svg` (or .png) - Physics simulation lab
- `ai_assistant.svg` (or .png) - AI Solution & Narration panel

### Recommendations:
- **Format**: Vector SVG is best for Retina and zoom clarity.
- **Dimensions**: Square aspect ratio (viewBox="0 0 24 24" or 64x64 / 128x128 px).
- **Background**: Transparent background.
